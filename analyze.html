IOC extractor

Paste an email, report or log (up to 500 KB). Defanged indicators are refanged first. Private IPs and internal names are left out, with a count of what was dropped.

What does this mean?

These are things in your text that could identify an attacker: web addresses, IP addresses, file fingerprints (hashes) and vulnerability IDs. Finding one doesn't mean it's bad. Look up the ones you don't recognise, one at a time.

Suspicious-link inspector

Paste one URL. This page never opens or fetches it; it only reads the text: the real host, tricks like paypal.com@evil.example, look-alike brand names, encodings and redirects.

What does this mean?

The verdict comes only from reading the link's text; the link was never opened. “Suspicious” means it uses a trick scammers use, like a look-alike brand name or a hidden real address. If you weren't expecting it, don't click it: type the site's address yourself instead.

Email-header analyzer

Paste the raw headers of a message (Gmail: ⋮ → Show original; Outlook: View → View message source). Headers include your own address; they are read here and never leave the page.

What does this mean?

Email headers record which servers handled a message. SPF, DKIM and DMARC check that the sender is allowed to send for that domain: “pass” is good, “fail” means the message may be forged. Replies or bounces going to a different domain than the sender is a common phishing sign.

JWT decoder

Decodes a JSON Web Token's header and payload in your browser. It does not verify the signature, and the token is not sent anywhere. Treat live tokens like passwords.

What does this mean?

A JWT is a login token. This shows what's written inside it, not whether it's genuine: the signature isn't checked. Treat a real token like a password: anyone who has it may be able to act as you until it expires.

File analyzer

Hashes, real file type and readable strings, worked out in your browser. The file is never uploaded. Up to 50 MB.

What does this mean?

The hashes are the file's fingerprints: use Look up to see if the file is already known as malware, without uploading it. A warning about the file type means its name doesn't match what's really inside, a common trick to get you to open it.

Subnet calculator

What does this mean?

A subnet is a block of network addresses. The first (network) and last (broadcast) addresses are reserved; the usable range is what devices can actually be given.

Certificate viewer

Paste a PEM certificate (or a chain), or drop a .cer, .crt or .der file. It is read in your browser. Paste certificates only: never a private key.

What does this mean?

A certificate proves a website's identity. Check that it's in date and issued to the name you expect. “Self-signed” means no trusted authority vouches for it, which is normal for internal test systems but not for public websites.

Nmap viewer

Drop the XML from a scan you ran (saved with -oX, up to 20 MB) to get a filterable table. It is read in your browser; private addresses are shown, and only public ones get a Look up link.

What does this mean?

Each open port is a door into that machine where a program is listening. Close or firewall anything that doesn't need to be reachable, and keep the listed software up to date.

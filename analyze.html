Analyze

Paste-and-check tools that run entirely in your browser. Nothing you paste is sent anywhere; only a Look up click on one extracted indicator calls the lookup service.

Tools: IOC extractor Link inspector Email headers JWT decoder File analyzer Subnet calculator

IOC extractor

Paste an email, report or log (up to 500 KB). Defanged indicators are refanged first. Private IPs and internal names are left out, with a count of what was dropped.

Suspicious-link inspector

Paste one URL. This page never opens or fetches it; it only reads the text: the real host, tricks like paypal.com@evil.example, look-alike brand names, encodings and redirects.

Email-header analyzer

Paste the raw headers of a message (Gmail: ⋮ → Show original; Outlook: View → View message source). Headers include your own address; they are read here and never leave the page.

JWT decoder

Decodes a JSON Web Token's header and payload in your browser. It does not verify the signature, and the token is not sent anywhere. Treat live tokens like passwords.

File analyzer

Hashes, real file type and readable strings, worked out in your browser. The file is never uploaded. Up to 50 MB.

Subnet calculator

Everything on this page runs locally. Domain checks use a copy of the Public Suffix List bundled with the site.
